Cambios concretos a implementar

  1. Font: Outfit → Inter Tight (mas condensada, profesional)
  2. Primary color: #0466C8 → #1a1a1c (negro elegante, como Nexsas)
  3. Background: #F8FAFC → #f4f5f8 (gris neutro frio)
  4. Cards: sombra MUI → borde sutil #dfe4eb + bg #fcfcfd
  5. Chips/Badges: colores pastel Nexsas (green-light, cyan-light, yellow-light) + rounded-full
  6. Sidebar active: fondo gris → fondo negro (#1a1a1c) con texto blanco
  7. Welcome card: gradiente → fondo negro solido #1a1a1c
  8. Text colors: usar opacidades (0.5, 0.4) para secundarios en vez de grises fijos
